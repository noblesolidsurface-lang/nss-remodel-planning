# NSS Home remodel planning resources

Free whole-house planning checklist and Spec Sheet Clipper extension by NSS Home.

[Open the checklist](https://noblesolidsurface-lang.github.io/nss-remodel-planning/)

[Spec Sheet Clipper](https://noblesolidsurface-lang.github.io/nss-remodel-planning/spec-sheet-clipper/)

The extension stores product selections locally. It has no analytics, server upload or account requirement. Chrome Web Store submission is pending. The ZIP contains readable HTML, CSS and JavaScript source.
